# Orclab v24: PHP as a web back end — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PHP back end is a stack Orclab knows: `stack-php` says how one is built, tested, linted, secured and containerised — every command in it having been run in a container on this machine — `/orc-test` and `lint_on_write` run its tools, `/orc-code` offers it on the web row, and a handoff file tells the first real project's session what to do and what to record.

**Architecture:** Prove first, then write (spec §2). Task 1 decides the framework and toolchain from live sources and writes only the parts of the skill that are research answers; Task 2 builds the image, runs every tool inside it on a sample project, and keeps the output as fixtures; Tasks 3–4 build `php.py` and the `.php` linter row against those fixtures and then run them for real through the container; Task 5 finishes the skill from what ran; Tasks 6–7 are `/orc-code` and the handoff; Task 8 closes. The image lives on this machine from Task 2 to Task 8 and is removed there.

**Tech Stack:** Python 3.12 / pytest for Orclab's own code; Podman 4.9.3 + podman-compose 1.0.6 (installed, confirmed 2026-09-20; no images present); the official `php` image with Composer; PHPUnit, a coverage driver (PCOV or Xdebug), Infection, `composer audit`, PHPStan — each a candidate until Task 1 confirms it and Task 2 runs it; Markdown skills.

**Spec:** `docs/superpowers/specs/2026-09-20-orclab-v24-php-design.md`. Read it first; each task names the section it rests on.

import pathlib

from orc_test import probe
from orc_test.langs import php
from orc_test.model import Coverage, Mutation

FIX = pathlib.Path(__file__).parent / "fixtures"


def test_markers_and_source_ext():
    assert php.MARKERS == ["composer.json"]
    assert php.SOURCE_EXT == ".php"


def test_missing_wants_composer_and_phpunit(tmp_path, monkeypatch):
    (tmp_path / "composer.json").write_text('{"require-dev": {"phpunit/phpunit": "^12"}}')
    monkeypatch.setattr(probe, "which", lambda n: False)
    assert php.missing(tmp_path) == ["composer"]
    monkeypatch.setattr(probe, "which", lambda n: True)
    assert php.missing(tmp_path) == []


def test_test_and_coverage_cmds(tmp_path):
    out = tmp_path / "out"
    assert php.test_cmd(tmp_path, None) == ["vendor/bin/phpunit"]
    assert php.test_cmd(tmp_path, "tests/Unit") == ["vendor/bin/phpunit", "tests/Unit"]
    cmd = php.coverage_cmd(tmp_path, None, out)
    assert cmd[:2] == ["vendor/bin/phpunit", "--coverage-clover"] and cmd[2] == str(out / "clover.xml")
    assert "--coverage-html" in cmd


def test_coverage_parse_reads_clover(tmp_path):
    out = tmp_path / "out"
    out.mkdir()
    (out / "clover.xml").write_bytes((FIX / "clover.xml").read_bytes())
    cov = php.coverage_parse(tmp_path, out)
    assert cov.total > 0 and cov.covered <= cov.total
    assert any(p.endswith("Greeting.php") for p in cov.files)


def test_coverage_parse_no_report(tmp_path):
    assert php.coverage_parse(tmp_path, tmp_path) == Coverage(0, 0)


def test_mutation_needs_infection_in_require_dev(tmp_path):
    (tmp_path / "composer.json").write_text('{"require-dev": {}}')
    assert "infection/infection" in php.mutation_unavailable(tmp_path)
    (tmp_path / "composer.json").write_text('{"require-dev": {"infection/infection": "^0.30"}}')
